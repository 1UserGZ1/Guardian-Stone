# 护道石 Guardian Stone

> 一块刻着归属的石头，跨越维度，把你带到同伴身边。

护道石是一个为 Minecraft Fabric 26.2 打造的轻量级传送模组。它用两块相互绑定的小石头，让远在天边的好友也能瞬间重逢——不论你们相隔多少方块，甚至跨越维度。

---

## ✨ 核心功能

### 🪨 两块石头，一条命脉

- **主护道石（Main Guardian Stone）** —— 由你自己合成，归属权绑定你的 UUID，只有你能使用。
- **子护道石（Child Guardian Stone）** —— 同样由你合成，归属权同样绑定你。把它交给你的朋友，就相当于给了他们一张"随时来找我"的通行证。

每次合成，护道石会自动记录**合成者的 UUID**（归属判定）和**游戏名**（仅用于显示）。玩家改名不会影响归属判定。

### 🌀 一键传送，无视维度

当你手持自己的主护道石并右键时，模组会在所有在线玩家中搜索**身上携带你子护道石**的人。找到目标后：

- **只有 1 个目标** → 直接传送。
- **有多个目标** → 弹出选择界面，让你挑选想去谁身边。

传送**不受无作弊限制**，支持**跨维度**。到达后，你和目标都会获得增益：

- 🛡️ 伤害吸收 III（5 秒）
- 💚 生命恢复 III（5 秒）
- 🔥 抗火（60 秒）
- 对目标周围 10 格内的敌对生物施加虚弱（30 秒）和缓慢 IV（10 秒）

### 🛠️ 耐久与冷却

- 主护道石拥有 **10 点耐久**，每次成功传送消耗 1 点，耗尽后消失。
- 传送成功后进入 **10 秒冷却**，物品栏会显示原版冷却动画。
- **取消选择不消耗耐久、不触发冷却**——人性化设计。

### 📜 合成配方

**主护道石：**

```
哭泣黑曜石    末影珍珠    哭泣黑曜石
末影珍珠      末影之眼    末影珍珠
哭泣黑曜石    末影珍珠    哭泣黑曜石
```

**子护道石：**

```
黑曜石        紫水晶碎片  黑曜石
紫水晶碎片    末影之眼    紫水晶碎片
黑曜石        紫水晶碎片  黑曜石
```

### 🎁 创造模式与绑定

从创造模式物品栏取出的护道石**没有归属**。右键它，会自动绑定到你身上，动作栏提示"已绑定归属：你的名字"。之后就可以正常使用了。

### 💀 死亡不掉落

主护道石和子护道石拥有**死亡不掉落**属性。玩家死亡时，这两类物品不会掉落，原地保留在背包中。

## 🎯 设计理念

护道石的名字取自"护道"二字——它不只是一个传送工具，更是一份**信任的凭证**。子护道石交到谁手里，谁就是你可以随时抵达的人。我们希望它成为多人服务器里，朋友之间最温暖的那块石头。
